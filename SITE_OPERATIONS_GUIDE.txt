2. HOW TO TAKE DOWN THE SITE (STOP EVERYTHING)
================================================================================
When you want to stop serving your website to the public internet, follow these
steps:

METHOD A: ONE-CLICK QUICK STOP (RECOMMENDED)
---------------------------------------------
Double-click the file named:
  c:\Users\royal\OneDrive\Desktop\threat-sandbox\stop_live.bat

METHOD B: POWERSHELL COMMANDS
-----------------------------
Open PowerShell as your user and run:

  # 1. Stop the Cloudflare Tunnel immediately:
  Stop-Process -Name cloudflared -Force -ErrorAction SilentlyContinue

  # 2. Stop the Threat Sandbox Flask backend:
  Get-Process python -ErrorAction SilentlyContinue | Where-Object {
      $_.Path -like "*threat-sandbox*"
  } | Stop-Process -Force

  # 3. Release port 5000 if occupied:
  Get-NetTCPConnection -LocalPort 5000 -ErrorAction SilentlyContinue | ForEach-Object {
      Stop-Process -Id $_.OwningProcess -Force -ErrorAction SilentlyContinue
  }

METHOD C: COMMAND PROMPT (CMD)
------------------------------
Open Command Prompt and run:

  taskkill /F /IM cloudflared.exe
  wmic process where "name='python.exe' and commandline like '%%threat-sandbox%%'" delete

VERIFYING THE SITE IS DOWN:
---------------------------
Run:
  curl.exe -I https://buzz-cabinet-ensures-lead.trycloudflare.com
Result: Cloudflare will display HTTP 530 / Error 1033 (Origin DNS or tunnel closed).

5. HOW TO GET A PERMANENT CUSTOM DOMAIN VIA CLOUDFLARE (OPTIONAL & FREE)
================================================================================
TryCloudflare quick tunnels generate a new random URL each time you restart.
If you own a custom domain (e.g. `mysandbox.com`) registered on Cloudflare, you
can assign a permanent URL (e.g. `https://sandbox.mysandbox.com`) for free:

Step 1: Authenticate cloudflared with your Cloudflare account:
  & "$env:LOCALAPPDATA\cloudflared.exe" tunnel login
  (This opens a browser window to authorize your domain).

Step 2: Create a permanent named tunnel:
  & "$env:LOCALAPPDATA\cloudflared.exe" tunnel create threat-sandbox-tunnel

Step 3: Route your subdomain to the tunnel:
  & "$env:LOCALAPPDATA\cloudflared.exe" tunnel route dns threat-sandbox-tunnel sandbox.mysandbox.com

Step 4: Create config file %USERPROFILE%\.cloudflared\config.yml:
  tunnel: <Tunnel-UUID-from-step-2>
  credentials-file: C:\Users\royal\.cloudflared\<Tunnel-UUID>.json
  ingress:
    - hostname: sandbox.mysandbox.com
      service: http://127.0.0.1:5000
    - service: http_status:404

Step 5: Run your permanent tunnel:
  & "$env:LOCALAPPDATA\cloudflared.exe" tunnel run threat-sandbox-tunnel

6. TROUBLESHOOTING & HEALTH CHECKS
================================================================================
Q: I get "502 Bad Gateway" on Cloudflare.
A: The Flask app is not running on port 5000. Start it using:
   .\.venv\Scripts\python.exe app.py

Q: I get "Site can't be reached" or "429 Too Many Requests".
A: The platform has a built-in sliding-window rate limiter (20 URL scans/min,
   10 file uploads/min). Wait 60 seconds for the quota to replenish.

Q: How do I test local health without the internet?
A: In your browser, open: http://127.0.0.1:5000
   Or run: curl.exe -I http://127.0.0.1:5000

Q: How do I check if port 5000 is open?
A: In PowerShell, run:
   Get-NetTCPConnection -LocalPort 5000
